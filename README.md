# Neo Water · Опросный лист БМОС

Опросный лист для подбора блочно-модульных очистных сооружений (БМОС). Внутренний инструмент ООО Neo Drain.

## Что это

Одностраничное приложение (single HTML, без бэкенда), которое заказчик заполняет за 15–25 минут. Десять разделов: заказчик, объект, тип и объём стоков, состав на входе, требования к очистке, площадка, инженерные сети, технологические предпочтения, сроки и коммерческие условия, документация.

## Возможности

- Автосохранение черновика в localStorage браузера.
- Возобновление с последнего раздела.
- Сводка со всеми ответами в одном экране.
- Экспорт: копирование в буфер обмена, скачивание JSON, отправка по e-mail, печать / PDF.
- Без бэкенда — полностью статический сайт, разворачивается на GitHub Pages.
- Адаптив для десктопа и мобильных устройств.

## Локальный запуск

Просто откройте `index.html` в браузере. Никаких зависимостей.
